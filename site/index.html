MCP server for Archicad

Let your AI assistant work in Archicad.

Caracara connects Claude and other MCP clients to running Archicad projects. Ask in plain language to find, inspect, change or export elements, and it drives Archicad through the Tapir add-on and the official JSON API.

Download for Claude View on GitHub

Stable release, installs as a one-click MCP Bundle.

What it does

The full Archicad automation surface, shaped so an AI agent can use it without flooding its context or touching files it shouldn't.

351 Archicad commands

302 Tapir commands and 49 official JSON API commands, generated from their schemas and validated before anything reaches Archicad.

Query and mutate in one call

archicad_query finds elements by type, selection, classification or filter. archicad_mutate moves, rotates, edits, highlights or deletes them as one Undo step.

Element sets, not GUID dumps

Queries return a short setId and a count. The GUIDs stay on the server, and detail reads return only the fields you ask for.

Built for long operations

Slow commands hand back a job handle instead of timing out. Large listings come in pages of 100.

Safe by default

Files Archicad writes are confined to one output folder. HTTP transports listen only on this machine unless you allow remote access with a token.

Several Archicads at once

Discover every running instance and send each command to the one you mean by its port. Works on Windows and macOS.

Get started

Five minutes, no Python setup. uv provisions Python and the locked dependencies itself.

Install the prerequisites

Run Archicad with the Tapir add-on installed, and install uv so it is on your PATH. Tested with Archicad 30 and Tapir 1.7.3.

Install the bundle

Download caracara-archicad.mcpb and open it with Claude Desktop, Claude Code or another client that supports MCP Bundles. For unreleased changes, use the weekly build instead.

Or configure it by hand

Add this to your client's MCP configuration (for Claude Desktop, claude_desktop_config.json):

{
  "mcpServers": {
    "ArchicadCaracara": {
      "command": "uvx",
      "args": [
        "--from",
        "git+https://github.com/parikshit99/Caracara-Archicad-MCP",
        "caracara-server"
      ]
    }
  }
}

Ask

Restart your client and try "Which Archicad projects do I have open?", then "Find every wall on the ground floor and highlight it in red."

The server can change the open project, export files, and send or receive Teamwork changes. Treat installing it like handing your AI client your Archicad seat.

Tools

A small toolset in front of the full command list, so the agent reaches for the high-level tools first.

ToolWhat it does
discovery_list_active_archicadsLists running Archicad instances and their ports, and flags ones that are unresponsive or missing Tapir.
archicad_queryFinds elements and reads their metadata; returns a set, element IDs, or just the fields you name.
archicad_mutateSets properties, moves, rotates, edits details, highlights or deletes a set of elements in one Undo step.
archicad_list_commandslow-levelLists every command with a short description.
archicad_get_command_schemalow-levelReturns the argument schema of one command.
archicad_call_toollow-levelRuns any command by name after validating its arguments.
archicad_get_jobGets the result of a long-running command, or lists recent jobs to recover a lost response.

Configuration options, HTTP transports and development setup are in the README.
